# ⚡ NovaHedge Global — Investor & Dual Hedging Web Platform

Platform FinTech Investor Portal & Hedging Monitoring eksklusif untuk brand **NovaHedge Global**.

---

## 📱 6 Modul Utama:

1. **💳 Dompet Token (Gas Fee & Profit Share 30%)**:
   - Saldo dompet token, estimasi Rupiah, tombol Isi Saldo & Tarik Dana.
   - Status approval penarikan (`✓ disetujui`).
   - 2x2 Metrik: Total Top-Up, Fee Profit (30%), Biaya VPS, Profit Kumulatif.
   - Proteksi **High-Water Mark (HWM)**: Rekor profit tertinggi.
   - Ringkasan Profit Pool Net (+18.12%).

2. **🏊 Pool Anda (PAMM / Pool Investasi)**:
   - **Pool A** & **Pool B** dengan porsi kepemilikan (%) dan total deposit.
   - Tag status realtime: `🔒 CYCLE BERJALAN sejak HH.mm`.
   - Distribusi profit diterima + Riwayat closing.
   - Fitur **Antre Keluar (Queue Withdrawal)** modal saat siklus selesai.

3. **📜 Jurnal Distribusi**:
   - Filter VPS.
   - Log profit-share per closing siklus.

4. **📈 Live MT5 Hedging Monitor**:
   - Kolom MASTER vs SLAVE.
   - Kurs Rupiah berjalan (Rate 17.745).
   - Bid/Ask live spread.
   - Equity, Saldo, Kredit Bonus.
   - Margin Call (MC) Price & jarak pips.
   - Margin Level %.
   - Detail pasangan tiket hedge dengan konversi Rupiah dan Net per tiket.

5. **🤝 Referal & Komisi Afiliasi**:
   - Kode Referal Unik (`9XTVX2`), Salin Link.
   - Komisi 33.3% dari setiap gas fee downline.
   - Omzet ajakan + Pohon jaringan downline.

6. **👤 Profil & Keamanan**:
   - Nomor WhatsApp/HP.
   - Tautkan Telegram Bot OTP (`@novahedgeglobalbot`).
   - Ganti Password.

## 🚀 Cara Menjalankan & Deploy:

### 1. Jalankan Lokal di Laptop / VPS:
```bash
node server.js
```
Akses di browser: `http://localhost:4000`

### 2. Deploy Gratis ke Cloud (Vercel / Render):
1. Upload folder `novahedge_global_platform` ke GitHub Anda.
2. Buka [Vercel.com](https://vercel.com) $\rightarrow$ Add New Project $\rightarrow$ Deploy!
3. Anda akan mendapatkan URL web resmi: `https://novahedge-global.vercel.app`.
