### ⛽ 4. BIAYA OPERASIONAL & MEKANISME "PREPAID GAS FEE"
Semua transaksi bagi hasil dan sewa infrastruktur berjalan otomatis via Web Platform tanpa penagihan manual:

1. **Biaya Dedicated Cloud VPS (5 USDT / Bulan):**
   * Setiap akun investor dialokasikan 1 instance Windows Cloud VPS khusus berkecepatan tinggi (*zero latency* ke server broker).
   * Biaya pemeliharaan server flat **5 USDT / Bulan**, otomatis dipotong dari saldo Gas Fee klien setiap 30 hari kalender.
   * Klien tidak perlu repot menyewa, merawat, atau memantau server sendiri.

2. **Deposit Gas Fee Awal (10% dari Modal):**
   * Contoh: Klien deposit modal trading **$10,000** di MT5.
   * Klien menyetor saldo Gas Fee awal di Web Platform sebesar **$1,000 USDT** (dipakai untuk biaya VPS 5 USDT/bulan dan pemotongan profit sharing otomatis).
3. **Potong Saldo Bagi Hasil Real-Time:**
   * Setiap kali bot menutup siklus Take Profit di MT5, saldo Gas Fee klien di web langsung terpotong secara otomatis sesuai persentase tier.
   * Hak komisi Mitra Introducer langsung otomatis tercatat di dompet mitra secara real-time.
4. **Sistem Pengaman Auto-Pause:**
   * Jika saldo Gas Fee menipis (<= $100), notifikasi otomatis terkirim via Telegram ke klien.
   * Jika saldo Gas Fee habis ($0), bot otomatis **PAUSE** (tidak membuka posisi baru) sampai dilakukan top-up.
   * Dana modal dan profit trading klien di akun MT5 tetap aman 100% di tangan klien sendiri.
